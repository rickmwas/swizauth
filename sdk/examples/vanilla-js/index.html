SwizAuth JavaScript SDK Demo

This demo shows how to integrate SwizAuth authentication into your application using the JavaScript SDK.

Configuration

First, configure your SwizAuth client:

const swizAuth = new SwizAuth.SwizAuthClient({
  clientId: 'your_client_id_here',
  domain: 'http://localhost:8080',
  organizationId: 'your_org_id_here' // Optional: pre-set organization
});

Authentication Methods

Sign In Widget

Embed the SignIn component directly into your page:

Widget

Code

<div id="signin-widget"></div>
<script>
// Using vanilla JS
SwizAuth.renderSignIn('#signin-widget', {
  onSignIn: () => console.log('Signed in!'),
  onError: (error) => console.error('Error:', error),
  appearance: {
    primaryColor: '#6366f1',
    logoUrl: 'https://example.com/logo.png'
  }
});
</script>

Sign Up Widget

Embed the SignUp component for user registration:

Widget

Code

<div id="signup-widget"></div>
<script>
SwizAuth.renderSignUp('#signup-widget', {
  onSignUp: () => console.log('Signed up!'),
  onError: (error) => console.error('Error:', error),
  appearance: {
    primaryColor: '#6366f1',
    backgroundColor: '#ffffff'
  }
});
</script>

User Profile Widget

Display and edit user profile information:

Widget

Code

<div id="profile-widget"></div>
<script>
SwizAuth.renderUserProfile('#profile-widget', {
  onUpdate: () => console.log('Profile updated!'),
  onError: (error) => console.error('Error:', error)
});
</script>

Organization Switcher Widget

Allow users to switch between organizations:

Widget

Code

<div id="org-switcher-widget"></div>
<script>
SwizAuth.renderOrganizationSwitcher('#org-switcher-widget', {
  onSwitch: (org) => console.log('Switched to:', org),
  appearance: {
    primaryColor: '#6366f1'
  }
});
</script>

Integration Guide

1. Install the SDK

npm install @swizauth/js
# or
yarn add @swizauth/js

2. Import and Initialize

import { SwizAuthClient } from '@swizauth/js';

const swizAuth = new SwizAuthClient({
  clientId: 'your_client_id',
  domain: 'https://auth.yourdomain.com'
});

3. React Integration

import { SwizAuthProvider, SignIn, useAuth } from '@swizauth/js';

function App() {
  return (
    <SwizAuthProvider config={{ clientId: 'your_client_id', domain: 'https://auth.yourdomain.com' }}>
      <AuthenticatedApp />
    </SwizAuthProvider>
  );
}

function AuthenticatedApp() {
  const { isSignedIn, user } = useAuth();
  
  if (!isSignedIn) {
    return <SignIn />;
  }
  
  return <div>Welcome, {user.firstName}!</div>;
}

4. Vanilla JavaScript

// Include the UMD build
<script src="https://cdn.jsdelivr.net/npm/@swizauth/js@latest/dist/swizauth.umd.js"></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@swizauth/js@latest/dist/swizauth.css">

<script>
const client = new SwizAuth.SwizAuthClient({
  clientId: 'your_client_id',
  domain: 'https://auth.yourdomain.com'
});

// Render components
SwizAuth.renderSignIn('#signin-container');
</script>
